# Dr. A. P. J. Abdul Kalam – Tribute Page

A responsive tribute webpage dedicated to Dr. A. P. J. Abdul Kalam, created as part of the Oasis Infobyte Web Development and Designing Internship.

## 🌟 About the Project

This project presents the life, achievements, contributions, and inspiring journey of Dr. A. P. J. Abdul Kalam.

The webpage includes:

- Hero section
- Biography / introduction
- Life timeline
- Major contributions and honours
- Inspirational quote
- Responsive design
- Local image asset

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design

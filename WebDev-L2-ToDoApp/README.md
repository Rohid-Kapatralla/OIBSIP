# 📝 To-Do Web Application

A simple and responsive To-Do Web Application developed as part of the Oasis Infobyte Web Development and Designing Internship.

## 📌 About the Project

This To-Do Web App helps users manage their daily tasks efficiently. Users can add new tasks, mark tasks as completed, delete individual tasks, and clear all completed tasks.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete individual tasks
- 🧹 Clear completed tasks
- 🔢 Display remaining task count
- 💾 Save tasks using browser local storage
- 📱 Responsive and user-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

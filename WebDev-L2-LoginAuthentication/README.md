# 🔐 Login Authentication System

A simple and responsive Login Authentication System developed as part of the **Oasis Infobyte Web Development and Designing Internship**.

## 📌 About the Project

This project demonstrates a front-end login authentication interface where users can enter their email and password and receive appropriate authentication messages.

The application includes form validation, password visibility control, remember-me functionality, and login status messages.

## ✨ Features

- 🔐 User login interface
- 📧 Email input validation
- 🔑 Password input validation
- 👁️ Show/Hide password functionality
- ☑️ Remember Me functionality using Local Storage
- ✅ Successful login message
- ❌ Invalid login message
- 🔗 Forgot Password demonstration
- 👤 Create Account demonstration
- 📱 Responsive design
- 🎨 Modern gradient-based user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
